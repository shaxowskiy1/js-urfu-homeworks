# Лабораторная работа №3. Знакомство с ЯП JavaScript

## Запуск

```bash
npm start
npm test
```

## Состав

| Файл | Задача | Сложность по времени | По памяти |
|---|---|---|---|
| `src/sort.js` | Сортировка слиянием | O(n log n) во всех случаях | O(n) |
| `src/binarySearch.js` | Бинарный поиск | O(log n), лучший случай O(1) | O(1) |
| `src/brackets.js` | Проверка баланса скобок `()[]{}<>` | O(n) | O(n) |
